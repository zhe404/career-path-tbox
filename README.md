# AI职业导航 · 最终整合版

包含两个模块：
- 职业规划：采用 8 月 16 日最新版职业规划页面与后台优化逻辑
- 职场模拟：保留原有互动式远程协作训练、六维评分和雷达图

## 启动
1. 复制 `.env.example` 为 `.env`
2. 填写 `TBOX_API_KEY` 和 `SIMULATION_APP_ID`
3. `npm install`
4. `npm start`
5. 浏览器访问 `http://localhost:8081`
